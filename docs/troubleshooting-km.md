# ការដោះស្រាយបញ្ហាបច្ចេកទេស PhoneToUSB (Troubleshooting Guide)

ឯកសារនេះណែនាំអំពីវិធីដោះស្រាយបញ្ហាទូទៅនៅពេលប្រើប្រាស់ប្រព័ន្ធ PhoneToUSB។

---

## ១. បញ្ហា Receiver បង្ហាញ "USB Not Ready" ឬ "Volume Not Found"

### មូលហេតុដែលអាចកើតមាន៖
1. USB Flash Drive ត្រូវបានដកចេញ ឬរលុង។
2. USB ត្រូវបានកំណត់ជា Read-Only (ការពារកុំឱ្យសរសេរ)។
3. កម្មវិធី PhoneToUSB.exe មិនត្រូវបានដំណើរការចេញពី USB ដោយផ្ទាល់។

### វិធីដោះស្រាយ៖
- ពិនិត្យមើលថាតើ Windows File Explorer អាចមើលឃើញ និងបើក USB នោះបានដែរឬទេ។
- សាកល្បងដក USB រួចដោតចូលរន្ធ USB ផ្សេងមួយទៀត។
- ត្រូវប្រាកដថាបានចម្លង និងដំណើរការ `PhoneToUSB.exe` ចេញពីក្នុង USB Flash Drive។

---

## ២. បញ្ហាទូរស័ព្ទបង្ហាញស្ថានភាព "Offline"

### មូលហេតុដែលអាចកើតមាន៖
1. កុំព្យូទ័រយួរដៃបានចូលទៅក្នុង Sleep Mode ឬបិទអេក្រង់ដែលធ្វើឱ្យ Wi-Fi ផ្អាកដំណើរការ។
2. កុំព្យូទ័រ ឬទូរស័ព្ទដាច់សេវាអ៊ីនធឺណិត។
3. Firewall ឬប្រព័ន្ធសុវត្ថិភាពរបស់ក្រុមហ៊ុនបានរារាំង WebSocket/WebRTC។

### វិធីដោះស្រាយ៖
- ចូលទៅកាន់ Windows Settings > Power & battery > កំណត់ "When plugged in, put my device to sleep after" ទៅជា "Never"។
- ពិនិត្យមើលថាតើ Windows Receiver បង្ហាញសញ្ញា "Online" ពណ៌បៃតងដែរឬទេ។
- ប្រសិនបើប្រើប្រាស់ Wi-Fi ក្រុមហ៊ុនដែលតឹងរ៉ឹង ប្រព័ន្ធនឹងប្តូរទៅប្រើប្រាស់ **TURN Relay** ដោយស្វ័យប្រវត្តិ។ សូមប្រាកដថា Port 3478 / 5349 មិនត្រូវបានបិទទាំងស្រុង។

---

## ៣. បញ្ហាមិនអាចស្កេន ឬផ្គូផ្គង (Pairing Failed)

### មូលហេតុដែលអាចកើតមាន៖
1. QR Code បានផុតកំណត់ (កូដនីមួយៗមានសុពលភាពត្រឹម ៣ នាទីប៉ុណ្ណោះ)។
2. អ្នកប្រើប្រាស់មិនបានចុច "Approve" លើអេក្រង់កុំព្យូទ័រទាន់ពេលវេលា។
3. កាមេរ៉ាទូរស័ព្ទមិនអាចចាប់រូបភាពច្បាស់។

### វិធីដោះស្រាយ៖
- ចុចបិទផ្ទាំង QR Code លើកុំព្យូទ័រ រួចចុច "Show Pairing QR Code" ម្តងទៀតដើម្បីបង្កើតកូដថ្មី។
- យកទូរស័ព្ទស្កេន រួចក្រឡេកមើលអេក្រង់កុំព្យូទ័រ ហើយចុចប៊ូតុង **"Approve"** ភ្លាមៗ។

---

## ៤. បញ្ហាផ្ទេរឯកសារយឺត ឬដាច់ពាក់កណ្តាលផ្លូវ (Transfer Interrupted)

### មូលហេតុដែលអាចកើតមាន៖
1. សេវាអ៊ីនធឺណិតចល័ត 4G/5G ខ្សោយ ឬដាច់រលាក់។
2. USB ត្រូវបានដកចេញអំឡុងពេលផ្ទេរទិន្នន័យ។
3. ទំហំផ្ទុកនៅលើ USB អស់ (Disk Full)។

### វិធីដោះស្រាយ៖
- PhoneToUSB មានប្រព័ន្ធ **Automatic Retry & Checksum**។ ប្រសិនបើដាច់បណ្ដាញបណ្ដោះអាសន្ន កម្មវិធីនឹងព្យាយាមភ្ជាប់ឡើងវិញដោយស្វ័យប្រវត្តិ។
- ប្រសិនបើការផ្ទេរបរាជ័យ ឯកសារបណ្ដោះអាសន្ន (`.part`) នឹងត្រូវបានលុបចេញដោយស្វ័យប្រវត្ត មិនធ្វើឱ្យខូចខាតឯកសារចាស់ ឬខ្ជះខ្ជាយទំហំ USB ឡើយ។
- ពិនិត្យទំហំទំនេររបស់ USB នៅលើផ្ទាំង Windows Receiver។
