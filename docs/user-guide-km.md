# សៀវភៅណែនាំការប្រើប្រាស់ PhoneToUSB (User Guide)

**PhoneToUSB** គឺជាប្រព័ន្ធគ្រប់គ្រង និងផ្ទេរឯកសារ USB Flash Drive ពីចម្ងាយប្រកបដោយសុវត្ថិភាពខ្ពស់ តាមរយៈប្រព័ន្ធអ៊ីនធឺណិត (Global Internet)។

---

## ១. គំនិតចម្បងនៃប្រព័ន្ធ (Core Concept)

- **USB Flash Drive គឺជាកន្លែងរក្សាទុកឯកសារពិតប្រាកដ និងជាចម្បង** (Authoritative Storage)។
- កម្មវិធីទូរស័ព្ទ Android ដើរតួជាផ្ទាំងបញ្ជាពីចម្ងាយ (Remote Interface) ដើម្បីមើល បើក បង្កើតថត ផ្ទុកឡើង (Upload) និងទាញយក (Download) ឯកសារដែលនៅលើ USB ពិតប្រាកដ។
- ប្រព័ន្ធនេះដំណើរការតាមរយៈអ៊ីនធឺណិតគ្រប់ទីកន្លែង ទោះបីជាទូរស័ព្ទប្រើប្រាស់ 4G/5G នៅទីកន្លែងផ្សេង ហើយកុំព្យូទ័រយួរដៃដោត USB នៅផ្ទះ ឬការិយាល័យភ្ជាប់ Wi-Fi ផ្សេងគ្នាក៏ដោយ។

---

## ២. សេចក្តីត្រូវការជាមូលដ្ឋាន

១. កុំព្យូទ័រដំណើរការប្រព័ន្ធប្រតិបត្តិការ **Windows 11** (ឬ Windows 10) ដែលមានភ្ជាប់អ៊ីនធឺណិត។  
២. ឧបករណ៍ **USB Flash Drive** ដែលមានទំហំផ្ទុកទំនេរគ្រប់គ្រាន់។  
៣. ទូរស័ព្ទ **Android** (Android 8.0 ឡើងទៅ) ដែលមានភ្ជាប់អ៊ីនធឺណិត (Mobile Data ឬ Wi-Fi)។

---

## ៣. របៀបដំឡើង និងចាប់ផ្ដើមប្រើប្រាស់លើកដំបូង

### ជំហានទី ១៖ ដំឡើងលើ USB Flash Drive (Windows)
១. ទាញយកឯកសារកញ្ចប់ `PhoneToUSB-Windows.zip` ពី GitHub Releases ផ្លូវការ។  
២. ពន្លា (Extract) ឯកសារទាំងអស់ចូលទៅក្នុង **ឫសគល់នៃ USB Flash Drive** របស់អ្នក (ឧទាហរណ៍ `E:\` ឬ `F:\`)។  
៣. ចុចបើកកម្មវិធី `PhoneToUSB.exe` ដោយផ្ទាល់ពីលើ USB (មិនចាំបាច់ដំឡើង Python ឬកម្មវិធីជំនួយផ្សេងៗឡើយ)។  
៤. កម្មវិធីនឹងស្វែងរក Drive USB ដោយស្វ័យប្រវត្ត ហើយបង្ហាញស្ថានភាព៖  
   - **USB: Ready** (USB ត្រៀមរួចរាល់)  
   - **Status: Online** (បានភ្ជាប់ទៅកាន់ប្រព័ន្ធសម្របសម្រួល)

### ជំហានទី ២៖ ដំឡើងកម្មវិធីលើទូរស័ព្ទ Android
១. ទាញយក និងដំឡើងឯកសារ `PhoneToUSB.apk` លើទូរស័ព្ទរបស់អ្នក។  
២. បើកកម្មវិធី PhoneToUSB ហើយអនុញ្ញាតសិទ្ធិចាំបាច់ (ដូចជាសិទ្ធិកាមេរ៉ាសម្រាប់ស្កេន QR Code ភ្ជាប់លើកដំបូង)។

---

## ៤. របៀបភ្ជាប់ឧបករណ៍ទាំងពីរ (Pairing Process)

១. នៅលើអេក្រង់ Windows Receiver សូមចុចប៊ូតុង **"Show Pairing QR Code"**។  
២. អេក្រង់នឹងបង្ហាញកូដ QR Code ដែលមានសុពលភាពត្រឹម ៣ នាទី (Single-use expiring token) ដើម្បីធានាសុវត្ថិភាព។  
៣. នៅលើទូរស័ព្ទ Android សូមចុចប៊ូតុង **"Scan QR to Pair"** ហើយយកទូរស័ព្ទទៅស្កេន QR Code នោះ។  
៤. នៅលើអេក្រង់ Windows នឹងលោតប្រអប់ផ្ទៀងផ្ទាត់សួរថា៖  
   `"Do you want to authorize phone 'Pixel 8' to access this USB?"`  
៥. សូមចុច **"Approve"** (យល់ព្រម) នៅលើកុំព្យូទ័រ។  
៦. ការភ្ជាប់ត្រូវបានបញ្ចប់! កម្មវិធី Android នឹងចងចាំអត្តសញ្ញាណកូដសម្ងាត់របស់ USB នេះជារៀងរហូត។ **អ្នកមិនចាំបាច់ស្កេន QR Code ម្ដងទៀតឡើយនៅពេលក្រោយ**។

---

## ៥. របៀបគ្រប់គ្រង និងផ្ទេរឯកសារ

### ៥.១ ការមើលបញ្ជីឯកសារ (Remote Browsing)
- ចូលទៅកាន់ផ្ទាំង **"USB Browser"** លើទូរស័ព្ទ។  
- អ្នកនឹងឃើញ Folder និងឯកសារពិតប្រាកដនៅលើ USB ដូចជា `Documents/`, `Photos/`...។  
- ឯកសារកម្មវិធី និងកូដសម្ងាត់ផ្ទៃក្នុង (នៅក្នុង `.phonetoUSB`) ត្រូវបានលាក់ដោយស្វ័យប្រវត្តិដើម្បីសុវត្ថិភាព។

### ៥.២ ការផ្ទុកឡើងឯកសារពីទូរស័ព្ទទៅ USB (Upload)
១. ចុចលើសញ្ញា **"+"** ឬប៊ូតុង **"Upload File"** លើទូរស័ព្ទ។  
២. ជ្រើសរើសឯកសារដែលចង់ផ្ញើ (អាចជ្រើសរើសច្រើនក្នុងពេលតែមួយ)។  
៣. កម្មវិធីនឹងធ្វើការបំបែកឯកសារជាកង់ៗ (Streaming Chunks) និងផ្ញើតាមរយៈបណ្ដាញសុវត្ថិភាព។  
៤. នៅពេលផ្ញើចប់ ១០០% Windows Receiver នឹងផ្ទៀងផ្ទាត់លេខកូដសម្ងាត់ SHA-256 ធានាថាឯកសារមិនខូចខាត រួចទើបសរសេរចូល USB។  
៥. បញ្ជីឯកសារលើទូរស័ព្ទនឹង Refresh បង្ហាញឯកសារថ្មីភ្លាមៗ។

### ៥.៣ ការទាញយកឯកសារមកទូរស័ព្ទ (Download)
- ចុចលើឯកសារណាមួយ រួចជ្រើសរើស **"Download"**។ ឯកសារនឹងត្រូវទាញយក និងរក្សាទុកក្នុងម៉ាស៊ីនទូរស័ព្ទរបស់អ្នក។

### ៥.៤ ការបង្កើត Folder, ប្តូរឈ្មោះ និងលុប
- អ្នកអាចចុចជម្រើសលើ Folder ឬ File ដើម្បី Rename, Move ឬ Delete។  
- រាល់ការលុប (Delete) នឹងមានផ្ទាំងសួរបញ្ជាក់ជានិច្ច ដើម្បីការពារការច្រឡំដៃ។

---

## ៦. ការដក USB ឬពេលដាច់អ៊ីនធឺណិត

- ប្រសិនបើកុំព្យូទ័រត្រូវបានបិទ ឬដក USB ចេញ កម្មវិធីលើទូរស័ព្ទនឹងបង្ហាញសញ្ញា **"Offline"** ឬ **"USB Missing"**។  
- ប្រព័ន្ធត្រូវបានរចនាមិនឱ្យសរសេរទិន្នន័យចូល Hard Disk របស់ Windows ដោយលួចលាក់ឡើយនៅពេលដក USB។  
- នៅពេលដោត USB វិញ ហើយកុំព្យូទ័រ Online នោះទូរស័ព្ទនឹងភ្ជាប់ឡើងវិញដោយស្វ័យប្រវត្តិ (Automatic Reconnection)។
